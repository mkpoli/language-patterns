# Card fonts

Latin subsets of the three families the site's type stack names, embedded in the
social cards so the rendering does not depend on the fonts a machine happens to
have installed. All three are licensed under the SIL Open Font License 1.1.

| File | Family | Source |
| --- | --- | --- |
| `inter-latin.woff2` | Inter | Rasmus Andersson, https://rsms.me/inter/ (subset via Google Fonts) |
| `source-serif-latin.woff2` | Source Serif 4 | Frank Grießhammer, Adobe, https://github.com/adobe-fonts/source-serif (subset via Google Fonts) |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | JetBrains, https://www.jetbrains.com/lp/mono/ (subset via Google Fonts) |
